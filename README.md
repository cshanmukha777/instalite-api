# InstaLite CRUD API

An Express 5 REST API implementing the InstaLite lab's `User` and `Post` CRUD routes with Prisma ORM and PostgreSQL. The code is organized into routes, controllers, and services so HTTP concerns remain separate from database queries.

## Requirements

- Node.js 20+ (Node 22 recommended)
- PostgreSQL

## Setup

```sh
npm install
cp .env.example .env
# Edit DATABASE_URL in .env for your local PostgreSQL database.
npm run db:generate
npm run db:migrate -- --name init
npm start
```

The server listens on port `3000` by default and prints `Server started on port 3000` after it begins listening. Set `PORT` to override it.

## Routes

| Method | Route | Result |
|---|---|---|
| `GET` | `/health` | `200`, `{ "status": "OK" }` |
| `POST` | `/users` | Create user (`201`); missing required fields `400`; duplicate username/email `409` |
| `GET` | `/users` | List users (`200`) |
| `GET` | `/users/:id` | Read user (`200`) or `404` |
| `PATCH` | `/users/:id` | Update `fullname`, `bio`, `isPrivate` only (`200`) or `404` |
| `DELETE` | `/users/:id` | Delete user (`204`) or `404` |
| `POST` | `/posts` | Create post (`201`); missing `imageUrl` `400` |
| `GET` | `/posts` | List posts (`200`) |
| `GET` | `/posts/:id` | Read post (`200`) or `404` |
| `PATCH` | `/posts/:id` | Update `caption`, `location` only (`200`) or `404` |
| `DELETE` | `/posts/:id` | Delete post (`204`) or `404` |

Unknown request-body fields are deliberately ignored by whitelisting accepted fields in service methods. IDs must be positive integers. Delete responses have an empty body.

## Project structure

```text
src/
  index.js                    Express app and server startup
  db.js                       One shared Prisma Client / PostgreSQL adapter
  routes/
    users.routes.js
    posts.routes.js
  controllers/
    users.controller.js
    posts.controller.js
  services/
    users.service.js
    posts.service.js
  utils/http.js                Shared ID and Prisma error helpers
prisma/
  schema.prisma
  migrations/                 Generated by Prisma migrate
```

## Quick smoke test

```sh
curl -i http://localhost:3000/health
curl -i -X POST http://localhost:3000/users \
  -H 'Content-Type: application/json' \
  -d '{"username":"riya_travels","email":"riya@example.com","fullname":"Riya Sharma"}'
curl -i http://localhost:3000/users
curl -i -X POST http://localhost:3000/posts \
  -H 'Content-Type: application/json' \
  -d '{"imageUrl":"https://example.com/photo.jpg","caption":"Weekend"}'
curl -i http://localhost:3000/posts
```

## Notes

- Never commit `.env` or database credentials.
- Prisma 7 uses `prisma.config.js` for schema/migration configuration and the PostgreSQL driver adapter configured in `src/db.js`.
- Database-backed route tests require a reachable database with migrations applied. `npm test` runs the unit/smoke checks included in `tests/`.
